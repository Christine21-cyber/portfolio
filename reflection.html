PROFESSIONAL REFLECTION

What this module taught me

What I learned during this module

More than any specific tool, this module taught me to be free creatively — to trust an idea enough to actually build it, rather than second-guessing it before I start. It also showed me how important teamwork is in IT: every project I worked on made more sense once I understood that everybody plays a specific role, and that good software depends on those roles fitting together, not on one person doing everything.

My strongest IT skill right now

A user-centred mindset. Working on the quiz app, the menu app, and the landscaping site pushed me to stop thinking only about the development side and start asking what the user would actually want from the screen in front of them — how they'd navigate it, what would confuse them, what they'd expect to happen next. That shift changed how I approach every new feature.

I stopped just thinking about the development, and started thinking about what the user would actually want.

— on shifting to a user-centred mindset

The skill I most want to improve

Writing more complicated code with confidence — the kind that lets a bigger, more ambitious idea actually work the way I picture it, instead of simplifying the idea to fit what I already know how to build.

How I plan to develop that skill

I'm going to deliberately pick my next few personal projects to be slightly beyond my current comfort zone rather than safe repeats of what I've already done, work through more advanced Kotlin and JavaScript concepts as I meet them instead of avoiding them, and get into the habit of reading other people's code on GitHub to see how more experienced developers structure complex logic.

How this portfolio supports my future studies and career

Having a public, evolving portfolio means my work doesn't disappear into old assignment folders once a module ends — it's something I can point an internship application or an interviewer to directly. I plan to keep adding to it as I build more complex projects through my Computer Science degree, so it grows alongside my actual skill level rather than staying frozen at where I am today.
